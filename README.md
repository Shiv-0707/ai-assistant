![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white) ![License](https://img.shields.io/badge/License-MIT-blue?style=for-the-badge)

## Overview
A versatile, Python-powered virtual assistant designed to streamline daily tasks through voice commands and automation. This assistant bridges the gap between manual input and intelligent execution, allowing for hands-free system control and information retrieval.

## Key Features
- Voice Recognition: High-accuracy natural language processing to understand user intent.
- - Web Automation: Instant searches on Google, Wikipedia, and YouTube.
  - - System Control: Seamlessly open applications, manage files, and execute system commands.
    - - Communication: Automated email sending and messaging capabilities.
      - - Productivity: Set reminders, alarms, and check real-time weather/news updates.
       
        - ## Installation
       
        - 1. Clone the repository:
          2.    ```bash
                   git clone https://github.com/Shiv-0707/ai-assistant.git
                   cd ai-assistant
                   ```

                2. Setup Virtual Environment:
                3.    ```bash
                         python -m venv venv
                         source venv/bin/activate  # On Windows: venv\Scripts\activate
                         ```

                      3. Install Dependencies:
                      4.    ```bash
                               pip install -r requirements.txt
                               ```

                            ## Usage
                        To start your assistant, simply run:
                  ```bash
                  python main.py
                  ```
                  *Note: Ensure your microphone permissions are enabled for voice command functionality.*
